# Automatizador de Mensajes - Pibox

Un generador web para personalizar mensajes de WhatsApp para el modelo **Entregas Optimizadas**. Permite buscar clientes, cargar contactos desde Excel, generar el mensaje con un solo clic y abrirlo directamente en WhatsApp.

## Características

- Buscador por nombre, ID de compañía o localidad.
- Plantilla con variaciones sutiles para evitar spam en WhatsApp.
- Soporte para zonas: Chapinero, Los mártires, Antonio Nariño o personalizada.
- Emojis personalizables o aleatorios (sutiles).
- Importación de `.xlsx` para teléfonos y correos.
- Botón para copiar al portapapeles y abrir en `wa.me`.
- Base de clientes precargada.
- Listo para desplegar en Vercel.
